Welcome to **KelDev**! KelDev is an open-source platform where developers solve real-world tasks via GitHub Pull Requests, earn skill reputation points, and generate verified skill certificates.

## ⚡ How It Works (Contributor Workflow)

Getting started is fast and straightforward:

1. **Create an Account & Set Up Profile**  
   Sign up on [KelDev](https://platform-dvoazj2pfjs66epbx6maig.streamlit.app) and complete your profile with your skills.

2. **Claim a Task**  
   Click on **"Find work"** to discover all available tasks matching your tech stack.

3. **Fork & Clone the Repository**  
   Fork the target repository to your GitHub account and clone it to your local machine.

4. **Execute the Task**  
   Read the task instructions, requirements, and constraints carefully in your editor, and build your solution!

5. **Deliver the Task & Earn Reputation**  
   Open a Pull Request from your fork to the original repository. Once your PR is merged, your reputation points and skill badges will be automatically credited to your profile. Good luck!
